# 详细总结指令模板

请按以下 10 段固定结构产出总结。默认使用中文(除非用户另指定语言)。即使内容较短,也照此结构组织,不要合并要点。

## 输出结构

1. **一句话结论**:整篇最核心的一句话判断。
2. **概述**:3–5 句,概括来源类型、立场与覆盖范围。
3. **背景与意图**:作者为什么写、面向谁、解决什么问题。
4. **核心要点**:列出 5–10 条编号要点;每条尽量带上关键数据、引文或时间戳。
5. **关键证据与反方观点**:区分作者观点、引用文本、评论/回复、第三方总结,不得混淆归属。
6. **争议与不确定性**:作者明确承认的局限、业界异议、证据缺口。
7. **作者结论**:作者最终的立场或建议,说明原文如何收尾。
8. **行动建议**:从内容能直接落地的下一步。
9. **一句话评价**:信息密度、适合谁读、值得花多少时间。
10. **元信息**:原始来源 URL、提取路径(CLI 直接提取 / 浏览器登录态提取)、本次总结是否已阅读原始全文。

## 写作要求

- 忠于原文,不臆造数据、引文或来源。
- 若有时间戳,标注到对应要点中,格式 `[MM:SS]`。
- 涉及音视频时,在要点处标注时间戳。
- 语言默认中文;用户指定其他语言时跟随。
